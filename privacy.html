개인정보처리방침

시행일 2026년 9월 2일 · URP

URP(이하 "회사")는 Provee 서비스를 운영하면서 이용자의 개인정보를 소중히 다룹니다. 이 방침은 회사가 어떤 정보를 왜 받고, 얼마나 보관하며, 이용자가 무엇을 요구할 수 있는지를 설명합니다.

1. 수집하는 개인정보

회원가입과 로그인

  • 이메일 주소
  • 이름 또는 표시 이름
  • 프로필 사진 (구글 계정으로 로그인한 경우, 구글이 제공하는 범위)

회사는 비밀번호를 직접 저장하지 않습니다. 로그인은 구글 계정을 통해 이루어집니다.

서비스를 이용하는 동안

  • 손글씨 풀이 데이터 — 이용자가 문제를 풀며 작성한 필기 이미지와 획의 순서·시간 정보
  • 학습 기록 — 푼 문제, 정답 여부, 풀이에 걸린 시간, 진단 결과, 복습 이력
  • 수강 과목 정보 — 대학생 이용자가 과목 지도 기능을 쓰기 위해 직접 입력한 학교·학과·수강 과목
  • 이용자가 직접 작성해 남긴 문의 내용

자동으로 생성되는 정보

  • 접속 일시, 브라우저 종류, 기기 종류, IP 주소
  • 서비스 이용 기록과 오류 기록
회사는 주민등록번호를 수집하지 않습니다. 결제 기능이 도입되기 전까지 결제 정보도 수집하지 않으며, 도입 시에는 이 방침을 미리 고쳐 알립니다.

2. 개인정보를 이용하는 목적

  • 회원 확인과 로그인 유지, 본인 여부 확인
  • 학습 진단과 개인별 학습 안내 제공
  • 손글씨 풀이를 읽어 어디서 막혔는지 분석하고 다음 학습을 제안
  • 수강 과목에 맞는 학습 경로와 과목 지도 제공
  • 문의 응대와 공지 전달
  • 서비스 오류 확인, 안정성 확보, 부정 이용 방지
  • 개인을 알아볼 수 없도록 처리한 뒤 서비스 품질 개선과 통계 분석에 이용

보관 기간이 지나거나 목적을 이룬 개인정보는 지체 없이 파기합니다. 전자 파일은 복구할 수 없는 방법으로 삭제하고, 종이에 출력된 것은 분쇄하거나 소각합니다.

5. 이용자와 법정대리인의 권리

이용자는 언제든지 다음을 요구할 수 있습니다.

  • 자신의 개인정보를 열람하는 것
  • 잘못된 정보를 고치는 것
  • 개인정보를 삭제하는 것
  • 처리를 멈추도록 요구하는 것
  • 동의를 철회하고 회원에서 탈퇴하는 것

요구는 아래 연락처로 하시면 됩니다. 회사는 지체 없이 처리하고 그 결과를 알려드립니다. 만 14세 미만 아동은 서비스에 가입할 수 없습니다.
